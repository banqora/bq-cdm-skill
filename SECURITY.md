# Security policy

Please do not disclose a suspected vulnerability in a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/banqora/bq-cdm-skill/security/advisories/new)
so the maintainer can investigate before details are published.

Include the affected version, operating system, reproduction steps, impact, and any suggested
mitigation. Do not include live credentials, confidential CDM data, or third-party production
artefacts in a report.

Security fixes target the latest release and `main`; older pre-1.0 releases may not receive a
backport. Ordinary bugs and documentation corrections can use the public issue tracker.
